# 1音だけ飛び出す音と、推敲(古典らしさへ寄せる最終段)

## 出発点

作曲者の感想(2026-09-27): 以前の生成は「メロディアスではない」「たまに音が一音だけズレる」「同じ音程をぐるぐる回しているだけ」だった。これらは Codex とのやりとりの前(#165 まで)の改修で改善されてきた。今も残っているという報告ではない。

そこで、この3つが今の生成にどれだけ残っているかを数えた。数えられて原因の段階まで特定できたのは、「一音だけズレる」の一部(下の定義の「1音だけ飛び出す音」)だけだった。今回はこれだけを直す。残りの2つは、下の「残したこと」に記録する。

## 調べたこと(非盲検、固定条件)

条件: 8進行(C・G・F・D・Am・Em・Eb・Dm)× Aメロ・サビ × 曲の雰囲気2つ(original-custom・dark-romantic)× seed 11・22・33、8小節、標準の作り方、公開ルール(アプリの既定と同じ経路)。1版につき 288 旋律。

実在曲の目安: OpenEWLD(https://github.com/00sapo/OpenEWLD 、パブリックドメインの歌のリードシート502曲)のコード記号付きの旋律を、生成と同じ8小節(32拍)の窓に分けた 1698 窓。リポジトリには入れず、数えた値だけをここに残す。

### Codex とのやりとりの前(#165、2c4905a)と、その後(#182、d22294e)

全体としてはっきり悪くなった所は見つからなかった。変わったのはサビ。

- サビの古典らしさの平均が 91.4 → 88.1 に下がった(Aメロは 95.4 → 96.3)
- サビで、同じ3音程の並びがくり返される割合が 0.041 → 0.086 に増えた。#168 以降の「コードが戻る所で核をくり返す」の効果で、意図した変化
- 実在曲の8小節の窓は 0.166 で、生成はどちらの版でもこれより少ない。「同じ音程をぐるぐる」は、音程の並びのくり返しの量では説明できない

### 調の外でコードにもない音

「一音だけズレる」の候補として最初に数えた。実在曲より少ない(8小節の窓: 実在曲 2.53、#165 1.80、#182 1.49 / 100音)。1拍以上、拍の頭で、コードの音と半音でぶつかる音も、実在曲と同じ程度(0.56、0.60、0.39 / 100音)。原因とは言えない。

### 1音だけ飛び出す音

定義(`isIsolatedLeap`): 1拍以下の音が、前の音からも次の音からも同じ向きに7半音以上離れている(1音だけ跳ねて、すぐ戻る)。

| | 実在曲(8小節の窓) | #165 | #182 |
|---|---|---|---|
| Aメロ | 0.57 / 100音 | 1.10 | 1.12 |
| サビ | (同上) | 0.54 | 0.46 |

Aメロは実在曲の約2倍。以前からある癖で、Codex とのやりとりの後に増えたものではない。

段階の記録(`stageTrace`)で、最終の音で飛び出している 60 か所について、その3音の形が最後にできた段階を数えた。

- 推敲(`final:refineTowardClassical`)33、サビの持ち上げ(`craft:lift`)15、組み立て 5、ほか 7
- 推敲の 33 か所のうち 24 か所は、推敲前の音から4半音以内の移動でできていた。何周かして4半音より動いたのは 9 か所

推敲の物差しは「跳躍の後に逆へ戻る」を良い形として数える。1音だけ飛び出す形はちょうどこれに当たるので、推敲は点数を上げるためにこの形を作っていた。

## 変更

推敲(`refineTowardClassical`)だけを変える。

1. 何周しても、推敲前の音から4半音より動かさない。コメントに書いてあった設計(1音あたり上下4半音まで)に実装を合わせる
2. 置き換えた音とその前後で、1音だけ飛び出す音が増える置き換えはしない

閾値と下限は変えていない。組み立て・サビの持ち上げでできる分は、この変更の対象外。

## 結果

調べるのに使った条件(上と同じ 288 旋律)では、1音だけ飛び出す音が Aメロ 1.12 → 0.56、サビ 0.46 → 0.13 / 100音 に減った。

調べるのに使っていない条件(`isolatedLeap.comparison.test.ts`、6進行 A・Bb・Cm・E・F#m・Ab × seed 71・83・97 × Aメロ・サビ × 8・16小節 × 雰囲気2つ、432 旋律)では、次のとおり。

| | 1音だけ飛び出す音(/100音) 前 → 後 | 古典らしさの平均 前 → 後 |
|---|---|---|
| Aメロ 8小節 | 0.48 → 0.31 | 92.91 → 93.60 |
| Aメロ 16小節 | 0.85 → 0.42 | 94.54 → 95.67 |
| サビ 8小節 | 0.85 → 0.36 | 89.29 → 90.11 |
| サビ 16小節 | 0.71 → 0.36 | 92.52 → 93.28 |

- 432 旋律のうち 160 旋律が変わった
- 5半音以上で数えても、4つとも減った
- ほかの記録(順次進行・連打・音の往復・狭い音域に留まる長さ)は、ほぼ変わらない
- 既存のテスト(下限を含む)はすべて通る

再現: 変更の前後それぞれで `ISOLATED_LEAP_OUT=<出力先>.json npx vitest run src/melody-engine/isolatedLeap.comparison.test.ts` を実行する。変更前のコードには `isIsolatedLeap` がないので、同じ定義を足して動かした。

## 残したこと

- 聴いて確かめていない。数の上で減ったことが、作曲者の言う「一音だけズレる」と同じものかは、まだわからない
- サビの持ち上げ(`craft:lift`)でできる分(15 か所)は残っている
- 「メロディアスではない」「同じ音程をぐるぐる」は、今回の物差し(音程の並びのくり返し・音の往復・狭い音域に留まる長さ)では実在曲との差が見つからなかった。聴いて気になった旋律を起点に、別に調べる
