# 旋律の性格：生成ロジックの修正（2026-10-18）

基準コミット98b71b6。同じ固定24曲×ヴァース/サビの48旋律で比較。測定条件と、修正前の段階別・ablation結果は [切り分け報告](melody-character-diagnosis-2026-10-18.md) に記録済み。実在曲の旋律は使用していない。長音1拍、裏拍±0.05拍、密度の定義、品質の式・閾値・重みは変更していない。

## 実装

- melodyCharacter.ts：seed・コード記号/低音/拍位置/長さ・テンポ・genre/aestheticから、音域・長音率・裏拍率・密度の目標を決める。UUIDに依存せず、追加の乱数消費もない。遅い/余白の多い曲では持続型の選択確率を上げるが、速い曲でも持続型を許す。
- generationParams / generateFromChords / motifCore：性格を生成の音域、音価パレット、密度、シンコペーション、休符へ渡す。サビの窓を広く、ヴァースを狭くする。小節頭は和声音へ、広いサビは低点と頂点を配置する。一律のピッチ拡大は品質が落ちたため採用しない。
- 最終の低点・頂点を一時的に保護して、周りの音を既存classicalRefinementで再推敲。保護Lockは処理中だけで、利用者のLock設定を書き換えない。推敲/品質選抜の撤去、指標の較正は行っていない。
- Performance：持続型の新規主旋律に限り、1拍以上の記譜音価をGateで縮めない演奏仕様を保持。長音直後の音も入口を守り、重ならないようにする。強弱は引き続き適用。既存仕様はオプション未指定なら従来どおり。
- useProjectStore：新規生成候補にのみ適用。取り込み素材・採用済み候補を後から変更しない。反復の土台がある場合は土台の性格/演奏仕様を継承する。保存・再読込で性格と演奏仕様が保持されることも検査。
- ユーザー承認に基づき、過去の発音位置/長さの一致・輪郭LCSの検査は、同じ旧13回の素材を使うmelodyConsonanceBaseline.test.tsへ移した。半音衝突関数そのものの不変性検査は残る。生成全体は新48旋律の分布・品質、旧12回の衝突/終止、既存全曲測定で検査する。

性格の数値は生成目標であり、和声/終止/息継ぎ/演奏を経た実測値と一対一ではない。検査は目標値でなく、実際の出力音符から算出している。標準standardプロファイルの測定であり、実音源による聴感の保証ではない。
