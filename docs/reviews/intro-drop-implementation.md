# イントロの「抜いて、頭で一斉に入れる」型の追加

参照した録音(個人の制作物、匿名)のアレンジの型を、アレンジ意図(`directive.intention`)の入口として追加した。
新しい画面・モード・プリセット・保存フィールドは追加していない。指示を出さない限り、出力は従来と同じ。

## 参照録音の観察(信号処理による推定。聴感の評価ではない)

録音は約4分35秒、テンポは約117.5 BPM(8小節がちょうど16.4秒)。楽器の判別と正確なコード推定はできない。

| 観察 | 確度 |
| --- | --- |
| 冒頭の8小節は、キックがほぼ無く、低域が弱く、中域と高域の質感が中心 | 中〜高 |
| 高域の質感は、イントロの終わりへ向けて約+7dB増える | 中 |
| 9小節目の頭で、全体が約+6dB、低域が+6dB、キックが入る(1小節あたり約30発音) | 高 |
| 左右の広がりは、イントロでは大きく、ドロップ後は中央寄りに狭まる | 中 |
| 途中に、低域とキックを約7小節抜く区間があり、戻すときに大きく入る(今回は未実装) | 中〜高 |
| 終わりは最後の約3小節のフェードアウト(今回は未実装) | 高 |

## 追加した規則

入口は既存の自由記述指示だけ。イントロを話題にして「ドラムレス」「一斉に入る」「キックと低域」のいずれかを言うときに働く
(例: 「ドラムレスで広がるイントロから、頭でキックと低域が一斉に入る」)。
低域を控えるヴァースの指示(`asksLowEndHoldBack`)とは言い回しを分け、お互いを巻き込まない。

- イントロ(4小節以上): キック・スネア系・clap・主ベース・補助ベース・コントラバスを区間の終わりまで保留する。
  Pad と Pad Air は区間の最初から最後まで鳴らす。高域の質感(High Glass)がある場合は、遅くとも区間の4分の3から入れる。
  境界のフィル(toms、field drum、transition phrase)は残し、ドロップへ向かう動きとして使う。
- イントロの直後(ブレイクダウンとアウトロは除く): 保留した層を区間の頭から一斉に入れる。キックと主ベースが
  その区間にまだ無ければ足す。
- 境界の分散処理(`scheduleBoundaryRoles`)と見直し(`refineBoundaryRoleSchedule`)は、この区間の入場を遅らせない。
  どちらも「1小節に交代2層まで」の既存の上限のために入場を小節ごとに散らすので、そのままだと一斉の入場が崩れる。
- `directive.preserve` / `add` に入れた層、`directive.sectionId` で別の区間に絞った指示には、触れない。
- 区間の `intention` の文言に、上の動きを一文ずつ追記する(既存の長区間の追記と同じ形式)。

## 実測(書き出したMIDIを再読込して測る。seed 1〜6)

Cm、4/4。構成は Intro / Verse8 / Pre8 / Chorus8 / Outro4。Intro は 4・8・16 小節で確認した。

| 測定 | 指示なし(従来) | 指示あり |
| --- | --- | --- |
| イントロの主ベース | 8小節のイントロで5小節目から鳴る | 鳴らない(全seed) |
| イントロの補助ベース | 5小節目から鳴る | 鳴らない(全seed) |
| キックの入場 | 区間の頭(Verse の1小節目) | 区間の頭(Verse の1小節目)。イントロでは鳴らない |
| Verse 1小節目で同時に鳴る保留対象の層 | キック系・スネア系のみ | 3層以上(キック・スネア・主ベース・補助ベース) |

- 指示なし、および無関係な指示(低域を控えるヴァース)の出力は、変更前の main と24パターンで一致した
  (イントロ8・16小節を含む2構成 × seed 6 × 指示 2 種)。
- 新しいテストは、変更前の生成コードでは4件が失敗する(保留・一斉入場・ブレイクダウンの扱い)。

## 検証

- 型チェック(`tsc -b`)成功、lint は既存の警告1件のみ(`importMidi.ts:174`)。
- テスト: `npx vitest run --maxWorkers=2` で 181ファイル成功・6スキップ、1389件成功・7スキップ、失敗0。
  作業前は 1382件。既存テストの期待値は変更していない。
- worker数を増やすと、既存の重い生成テスト(5秒の既定タイムアウト)が実行のたびに別のものから落ちる。
  変更前から起こる負荷由来の不安定さで、worker数2では起きない。

## 未実装・限界

- 左右の広がり(イントロは広く、ドロップ後は狭く): 区間ごとの広がりを持つ計画の項目が無いので、実装していない。
- 高域の質感の増加: 既に鳴る層(Pad Air、High Glass)の範囲のみ。層は足さない。
- 低域とキックを抜く中盤の区間、終わりのフェードアウト: 別の型として未実装。
- 入口は自由記述の指示のみ。専用のボタンやプリセットは無い。
- 録音の観察は信号処理による推定で、聴感の一致は保証しない。
