基点 main `a856fd20ffb3abb09d27875b1daa83554fe56baf`。実装は `928c41a`（反復配置・伴奏保持）と `42bfcf0`（再生成の発音小節保持）。独立テストは Claude Code 提出 `a6f71d2` を内容無変更で cherry-pick `98617a8`。この報告書の追加は音符生成を変更しない。

## 変更した動作

サビ・大サビは先頭2小節と末尾1小節を空けた範囲で毎小節の型を試し、単音の区間は2小節おきに試す。ブレイクダウンは従来のまばらな単音、ヴァース・アウトロは無音。単音区間を既にストラムが担当している場合はその伴奏を維持し、別の単音区間を候補にする。採用区間数上限・エネルギー条件は従来どおり。

リフ小節ではストラムを止め、アルペジオは既存の先頭音だけを残す。残す音の時刻・音高・長さを変更せず、全休符化で管理層の入退場が増えることを避ける。境界整理後に区間全体の半分（単音は1/4）に届かない反復区間を除き、毎回元案から伴奏を復元して再評価する。反復候補が成立しなければ、既存4候補を既存順序で試す。

再生成は既存の発音小節だけを訪問し、元の発音小節が欠ける案を棄却する。他トラック・対象区間外・保存音色・muteを保持する。安全・品質の条件により元案を返す場合がある。新しい設定・保存フィールド・公開APIは追加しない。

## 2回目のサビが0小節になる理由（Issue #213の追跡）

[段階別の追跡報告](guitar-riff-second-chorus-213.md)で原因を確認した。A/B新古典では2回目も5小節分生成されるが、区間内3・4小節目は既存管理2層の交代で境界予算が埋まり、riffの入口が遅れて3/8小節だけ残る。続く反復候補の4/8判定で区間を棄却し、旧伴奏へ戻る。2回目を生成対象から外す処理ではない。電子系には境界後2/8で棄却する例、未設定等には4/8を残しても候補全体の品質/聴感比較で戻る例もある。B未設定seed73は安全・品質条件を通り2回目も4/8。演奏処理・閾値は変更していない。
