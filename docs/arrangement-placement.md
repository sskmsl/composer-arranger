# 短いフレーズの配置: 主旋律の頂点と休みを取り合わない

アレンジの質を主旋律と同じ水準へ上げる施策の1つ目(`docs/codex-brief-arrangement-quality.md` の7章で Codex と合意した「配置・役割の競合を減らす」)。音高は直さず、置く場所だけを直す。

## わかったこと(開発用の条件、非盲検)

短いフレーズ・イントロ・対旋律・装飾の1案目を同じセクションに重ねて、配置の取り合いを数えた(`observeStack`、記録専用)。

- 2つ以上のレイヤーが同じ休みに入る(応答の位置の取り合い): Aメロ 15/74、サビ 23/73
- 8割以上埋まる休み: Aメロ 35/74、サビ 46/73
- 主旋律の頂点(最高音)で始まる音: Aメロ 16、サビ 21(頂点はそれぞれ 26・38)

レイヤーごとに分けると、頂点へ入っていたのは短いフレーズだった(Aメロ 14、サビ 16)。対旋律・装飾は 0 だった。短いフレーズ1つだけで埋める休みも、Aメロ 23、サビ 34 と他のレイヤー(2〜8)より多かった。

対旋律・装飾は、すでに主旋律の頂点(`protectedMoments`)と余白の評価(`assessReactiveNegativeSpaceFit`)を使っている。短いフレーズは、主旋律との音域・発音の重なりだけを点数にしていて、頂点と休みの埋まり方を見ていなかった。

## 変更

短いフレーズ(`generatePhrases.ts`)に、既存の評価を使う2つの対応を入れた。新しい物差しは作っていない。

1. **選抜**: 候補を選ぶとき、次の2つを差し引く(作り直しにも同じ補正をかける)
   - 対旋律・装飾と同じ余白の評価(`assessReactiveNegativeSpaceFit`)の不足(1点あたり 0.15)。候補が鳴る区間(候補の長さ)の中だけで評価し、候補の後ろの主旋律の休みは数えない
   - 主旋律の頂点(`protectedMoments` の highest-note)が鳴っている間に始まる音の数(1音あたり 6)
2. **削る**: 主旋律の頂点が鳴っている間に始まる音を削る。頂点の区間は、演奏処理後の主旋律から求めて、始まりと終わりを16分音符の格子にそろえる。入り(最初の音)と終止(最後の音)は残し、残りが4音未満(短いフレーズとして点数を付けない音数)になる場合は削らない。品質の点数は削った後の音で付ける

比較のため、`placement`(`current`・`select`・`trim`・`both`)で切り替えられるようにした。既定は `both`。

比べなかった案:

- **生成を見送る**: 短いフレーズは作曲者がボタンで頼んだときに作るので、見送ると何も返らない。今回は比べなかった
- **既存のモチーフを短く再提示する**: 別の作り方(イントロのモチーフを写す経路)が必要で、1つの施策に収まらないので、後の候補として残す

## 結果

`arrangementQuality.baseline.test.ts` を、`ARRANGEMENT_PHRASE_PLACEMENT` で4案に切り替えて数えた。確認用の条件は、施策を入れる前に固定し、比べる時に初めて動かした。

「4レイヤー」は、短いフレーズ・イントロ・対旋律・装飾(組み合わせ条件)の1案目を重ねたもの。品質の点数は、短いフレーズの既存の点数(`scorePhrase`)の全候補の平均で、Aメロ・サビを合わせた値。

読み取り(確認用の条件):

- 両方(both)で、短いフレーズが主旋律の頂点で始まる音は、Aメロ 9→1、サビ 10→3 に減った。4レイヤーで頂点に入る数も 10→2、13→6 に減った
- 短いフレーズだけで8割以上埋めた休みは 43→26、29→12 に減った。4レイヤーで8割以上埋まる休みも 50→35、35→25 に減った。2つ以上が入る休みは 16→12、13→13
- 品質の点数は 75.7→76.4 で、ほぼ変わらない。1案の音数は 21.0→19.9、21.2→20.5
- 削る(trim)だけでは、休みの埋まり方はほとんど変わらない。選抜(select)だけでは、音数が 14.5〜14.9 まで減る
- 開発用の条件でも、同じ向きだった

残したこと・気をつけること:

- サビでは、主旋律との平行5度・8度が 9→10 になった(同じ向きの組 88→80 のうち)。数が少なく、施策とのつながりは切り分けていない
- 聴いての確認はしていない。数の改善を、聴いた品質の改善とは扱わない
- 生成時間は、確認用の条件の短いフレーズ(24回)で 593→628ミリ秒で、ほぼ変わらない
- 候補の不足(候補が返らない)は、どの案でも 0
- イントロの中の装飾語彙の経路・装飾の旧来の独立した経路は、この変更の対象外
