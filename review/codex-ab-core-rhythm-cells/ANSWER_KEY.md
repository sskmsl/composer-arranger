# 答え(どちらがどの設定か)

**作曲者(Maさん)は、自分の試聴結果を伝えるまで開かないでください。**

- varied: 従来のサビの核の選び方(歌いやすさ×0.25 + hookability×0.37 + rhythmicIdentity×0.38)
- plain: 新しい「素直な型」(歌いやすさ×0.35 + cellHookability×0.6 + rhythmFit×0.05。cellHookability のリズムの項は rhythmicHookQuality)
